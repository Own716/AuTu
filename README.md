## 📖 简介 / Introduction

**AuTu** 是一款基于强大 **Mihomo** 内核深度打造的多平台代理客户端与网络调试工具箱。致力于提供轻量畅快、低资源消耗且长期稳定运行的现代客户端体验：

- 🎨 **“无界”现代视觉**：精致简洁的卡片式设计、Material You 动态色彩、沉浸式边到边布局与流畅的交互动效。
- 🛠️ **全能网络工具箱**：
  - **iPerf3 测速**：遵循官方网络测速协议的高性能带宽吞吐检测。
  - **DNS 诊断查询**：图形化解析与响应比对。
  - **本地 ICMP Ping**：快速追踪网络抖动与往返时延。
  - **STUN 协议 NAT 探测**：一键识别网络连通与穿透等级。
  - **流媒体解锁批量探测**：清晰呈现各节点流媒体可用性。
- ☁️ **WebDAV 云端备份**：配置与策略支持 AES 密码强加密云端自动备份。
- ⚡ **原生 16KB Page Size 适配**：完整支持 Android 15+ 全新内存架构标准。
- 🛡️ **纯粹安全**：开源透明、零内嵌追踪与广告。
