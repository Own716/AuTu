## 📖 简介 / Introduction

**AuTu for Android** 是一款专为 Android 平台打造的现代代理客户端，深度适配主流 Android 手机、平板及 Android TV 设备。基于高性能 Mihomo (Clash.Meta) 内核构建，集成了全协议栈支持、Material You 动态取色、低延迟规则分流、分应用代理（黑白名单）、WebDAV 云端备份与同步、通知栏快捷磁贴等丰富特性，兼顾极速连接、低功耗与清爽直观的视觉交互。

**AuTu for Android** is a modern network proxy client for Android, deeply customized and built on top of the high-performance Mihomo (Clash.Meta) core. It brings together full-protocol-stack support, Material You dynamic color theming, lightning-fast latency testing, customizable rule routing, per-app proxy, WebDAV cloud backup and sync, a Quick Settings tile, and Android TV support — all combined with blazing-fast connections, low battery consumption, and an elegant, clean user interface.

## ✨ Features / 功能亮点

- 🏝 **超级岛（实况更新胶囊）**：深度支持 Android 16 原生实况通知（Rich Ongoing Notifications）与各大主流 ROM 胶囊（OriginOS 原子岛、HyperOS 焦点通知、Flyme 灵动胶囊、ColorOS 流体云），挖孔屏旁极简常驻显示节点地区与连接状态。
- 🔔 **重构通知中心体验**：清晰呈现节点名称与上下行实时网速，展开态支持实时速率与累计流量双行展示，断开连接时瞬间销毁无幽灵残影。
- ⚡ **高性能内核**：基于 Mihomo (Clash.Meta) 内核，支持 TUN 模式、低延迟分流及规则组代理。
- 🎨 **自适应新图标与主题**：全新深浅双色品牌图标，支持应用内深浅色自由切换、系统模式无缝自动跟随，桌面与通知中心同步联动。
- 🎨 **Material You 现代设计**：全面支持动态配色、深色/浅色自适应主题、连续曲率圆角与丝滑手势交互。
- 📱 **深度 Android 系统适配**：支持下拉通知栏快捷磁贴（Quick Settings Tile）、分应用代理（应用白名单/黑名单模式）及 Android TV 遥控器与大屏适配。
- 🔄 **灵活的配置管理**：支持一键订阅导入、内置在线配置文件编辑器、规则与覆写脚本、WebDAV 云端备份与同步。
- 📊 **可视化网络洞察**：实时连接监控、请求分析、DNS 查询日志记录与核心运行诊断。
- 🛡 **开源纯粹无广告**：完全透明、无任何第三方追踪或数据收集，纯净安全。

### 📦 架构说明 / Architecture Notes

* **ARM64 (v8a)**: 适用于绝大多数现代主流 64 位 Android 手机与平板设备（强烈推荐）；
* **ARMeabi-v7a**: 适用于较老旧的 32 位 Android 设备或部分 TV 电视盒子；
* **x86_64 / x86**: 适用于 PC 端主流 Android 模拟器或 x86 架构 Android 设备；
* **Universal**: 通用架构安装包，包含所有架构二进制，体积稍大但适配所有设备。
